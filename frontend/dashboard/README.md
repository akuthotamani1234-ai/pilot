# Qpilot enterprise dashboard (Gate I)

React + TypeScript surface for blueprint progress and enterprise readiness.

```bash
cd frontend/dashboard
npm install
npm run build
```

Serve the built files from the Qpilot API at `/dashboard/` (see `backend/server.py`).  
This scaffold does **not** complete Gate I: multi-tenant auth, approvals UX, and production hosting remain open.
