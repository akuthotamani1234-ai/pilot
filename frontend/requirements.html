    Execution Center

    Choose what to test and where. Qpilot opens the application in a real browser, finds the pages and controls, runs the steps and checks the expected results. Results come only from what really ran.

    Testing strategy
    What to run

    Requirement tests need an AI to turn each test case into browser steps; without one they are reported as not automated, never as passed. Checkout, payment and deleting data are never performed in the test environment.
